## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues on `rubichandrap/bootcamp`, managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at root + `docs/adr/`. No `CONTEXT-MAP.md`. See `docs/agents/domain.md`.

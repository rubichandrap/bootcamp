# 6-Module Go Mastery Curriculum Roadmap

We decided to structure the Go Track into 6 core Modules focusing on deep, idiomatic Go concepts:
1. **Module 1: Go Fundamentals & Memory Models** (Pointers, structs, value vs reference semantics, slice header internals, map memory layouts).
2. **Module 2: Methods, Interfaces & Composition** (Implicit interface satisfaction, interface tuples `(type, value)`, composition over inheritance, type assertions).
3. **Module 3: Idiomatic Error Handling** (Sentinel errors, custom error structs, error wrapping `%w`, `errors.Is`/`As`, `defer`, `panic`/`recover`).
4. **Module 4: Concurrency & Channel Patterns** (Goroutines, buffered/unbuffered channels, `select` fan-in/fan-out, `sync.WaitGroup`, `sync.Mutex`, race detector).
5. **Module 5: Standard Library & Context Pipeline** (`io.Reader`/`io.Writer`, `context.Context` cancellation/deadlines, `net/http` server patterns).
6. **Module 6: Advanced Go Systems & Performance** (Generics, escape analysis, profiling with `pprof`, `unsafe` package, micro-benchmarks).

Each Module contains Reading Chapters, Challenge Chapters, and ends with a compulsory Assessment Chapter.

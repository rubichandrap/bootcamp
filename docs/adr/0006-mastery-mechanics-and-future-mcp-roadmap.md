# Anti-AI Dulling Mastery Mechanics and Future MCP Roadmap

We decided on the following mastery mechanics to rebuild hands-on programming intuition:
1. **Socratic Conceptual Hints**: Conceptual guidance without copy-pasteable solution code.
2. **Performance & Allocation Diagnostics**: Benchmark tab displaying `B/op`, `allocs/op`, and compiler escape analysis.
3. **Restricted Solution Reveal**: Solutions unlock only after passing or 3 failed attempts.

## Future Roadmap (V2)
- **MCP Server Integration**: Expose an MCP server so external AI tools (like Claude/Antigravity) can connect to the platform workspace for Socratic voice/text pair programming.

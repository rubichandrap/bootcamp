## Issue Closing Policy

Never include auto-closing keywords (`Closes #X`, `Fixes #X`, `Resolves #X`) in branch commit messages while pushing. GitHub issues must ONLY be closed when merging Pull Requests into `main` (or via `gh issue close` at PR merge time).

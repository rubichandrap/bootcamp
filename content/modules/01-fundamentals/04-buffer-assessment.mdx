# Module 1 Capstone Assessment: Fixed-Size Byte Buffer

Congratulations on reaching the Module 1 Assessment!

To prove complete mastery over Go memory allocation, value/pointer semantics, and slice headers, you must implement a zero-allocation `Buffer` struct.

## Requirements

1. `NewBuffer(capacity int)` initializes an empty byte buffer with pre-allocated capacity.
2. `Write(p []byte)` appends data from `p` into `b.buf` without exceeding pre-allocated capacity and returns bytes written (`n`).

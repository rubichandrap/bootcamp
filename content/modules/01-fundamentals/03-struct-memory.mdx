# Struct Memory Layout & Alignment

Go compiler aligns struct fields according to their byte sizes. Pointer receivers (`*T`) allow methods to mutate struct memory directly on the stack or heap without making a copy.

## Challenge

Implement the `Reset()` method on `*Stats` to clear all count and active values.

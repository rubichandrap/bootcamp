# Slice Header Internals & Mutability

In Go, a **slice** is not an array. A slice is a lightweight 3-word struct header:

```go
type SliceHeader struct {
    Data uintptr // Pointer to backing array
    Len  int     // Length
    Cap  int     // Capacity
}
```

## Challenge

Implement `AppendInt(slice []int, val int) []int` to append `val` to `slice` and return the modified slice.

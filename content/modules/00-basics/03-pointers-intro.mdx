# Pointers & Memory Addresses 101

In Go, a **pointer** holds the memory address of a variable.

## Key Syntax
- **`&` (Address-of Operator)**: Generates a pointer to its operand (`p := &x`).
- **`*` (Dereference Operator)**: Accesses or mutates the underlying value stored at the pointer's address (`*p = 100`).

```go
func Double(val *int) {
    *val = *val * 2 // Dereference to mutate caller variable
}
```

## Challenge

1. Implement `DoublePointer(val *int)` to double the integer value at address `val`.
2. Implement `Swap(a, b *int)` to swap the integer values at memory addresses `a` and `b`.

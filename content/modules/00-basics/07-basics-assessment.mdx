# Module 00 Capstone: Task Pipeline

Congratulations on completing the beginner Go syntax chapters!

In this **CapStone Assessment**, you will demonstrate your understanding of structs, slices, goroutines, and channels by building a concurrent task streaming pipeline.

## Requirements

1. `ProcessTasks(tasks []Task) <-chan string` receives a slice of `Task` structs.
2. It returns a read-only channel `<-chan string`.
3. In a background goroutine, it formats each task into `"Task <ID>: <Payload>"` and sends it onto the output channel.
4. Close the output channel when all tasks in the slice have been processed.

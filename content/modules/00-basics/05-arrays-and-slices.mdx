# Arrays & Slices Fundamentals

In Go, an **array** has a fixed length defined at compile time (`[5]int`), while a **slice** is a dynamically sized, flexible view into an underlying array (`[]int`).

## Creating & Appending Slices

```go
// Literal declaration
s := []int{1, 2, 3}

// Using make(type, len, cap)
buf := make([]int, 0, 10)

// Appending items
buf = append(buf, 42)
```

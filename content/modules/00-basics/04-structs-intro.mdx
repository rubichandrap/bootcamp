# Structs & Methods

A **`struct`** is a typed collection of fields used to group related data together.

```go
type User struct {
    Name string
    Age  int
}
```

## Pointer Receivers vs Value Receivers

Methods in Go can have **value receivers** `(u User)` or **pointer receivers** `(u *User)`:
- **Value receiver**: Operates on a copy of the struct. Changes do not affect the original caller.
- **Pointer receiver**: Operates on a pointer to the struct. Mutates the original caller state.

```go
func (u *User) Birthday() {
    u.Age++ // Mutates receiver
}
```

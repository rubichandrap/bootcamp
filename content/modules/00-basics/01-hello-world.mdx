# Hello World in Go

Welcome to Go! Go is a statically typed, compiled programming language designed at Google for simplicity, speed, and concurrency.

## Go Package & Function Syntax

In Go:
- Every source file begins with a `package` declaration.
- Code execution starts in `package main`.
- Functions are declared using the `func` keyword with explicit return types.

```go
package main

func HelloWorld() string {
    return "Hello, World!"
}
```

## Challenge

Implement the `HelloWorld()` function so that it returns the exact string `"Hello, World!"`.

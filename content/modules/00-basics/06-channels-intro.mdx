# Goroutines & Channels 101

Go features built-in concurrency primitives: **goroutines** and **channels**.

## Goroutines

A **goroutine** is a lightweight thread managed by the Go runtime. You start a goroutine with the `go` keyword:

```go
go myFunction()
```

## Channels

Channels are pipes that connect concurrent goroutines. You send values into channels with `ch <- val` and receive values with `val := <-ch`.

```go
ch := make(chan string) // Unbuffered channel

go func() {
    ch <- "hello" // Send message
}()

msg := <-ch // Receive message
```

## Challenge

Implement `SendMsg(ch chan<- string, msg string)` to spawn a background goroutine that sends `msg` into the channel `ch`.

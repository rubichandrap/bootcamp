# Assessment: Machinery Toolkit

Integrate descriptors, metaclasses, `__slots__`, context managers, and the import system to build a small machinery toolkit. All five areas from this module must be applied correctly to pass.

## Tasks

1. Implement the `ReadOnly` descriptor so `Settings().version` reads the stored value and assignment raises `AttributeError`.
2. Implement the `AutoLabel` metaclass so its `__new__` injects a `label` attribute equal to the lowercased class name.
3. Add `__slots__ = ("value",)` to `Slim` so instances have no `__dict__`.
4. Implement `Recorder` so entering appends `"enter"` to the shared log and exiting always appends `"exit"` (even when the block raises).
5. Implement `import_attr(module, attr)` using `importlib.import_module` and `getattr` to load any module and return one of its attributes.

# Metaclasses & `__slots__` Challenge

Now that you have read about metaclasses, `__init_subclass__`, and `__slots__`, apply what you learned!

## Tasks

1. Implement the `AddGreeting` metaclass so its `__new__` injects a `greet()` method returning `"hello"` into the namespace of every class it creates.
2. Add `__slots__ = ("x", "y")` to `SlottedPoint` so instances have no `__dict__` and reject unknown attributes with `AttributeError`.
3. Implement `Tracked.__init_subclass__` so every subclass registers itself in the `Tracked.subclasses` list.

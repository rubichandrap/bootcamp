# Descriptors Challenge

Now that you have read about the descriptor protocol, `property`, and `__set_name__`, apply what you learned!

## Tasks

1. Implement the `ReadOnly` descriptor so `Config().max_retries` reads the stored value and assigning to it raises `AttributeError`.
2. Implement `Temperature` so `celsius` stores through a validating setter (rejecting values below absolute zero with `ValueError`) and `fahrenheit` computes `celsius * 9 / 5 + 32`.
3. Implement the `PositiveNumber` descriptor using `__set_name__` so `Order.quantity` rejects non-positive values with `ValueError` and otherwise stores per-instance values.

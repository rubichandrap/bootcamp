# Context Managers & Import System Challenge

Now that you have read about context managers, `contextlib`, and the import system, apply what you learned!

## Tasks

1. Implement `Timer` so entering the `with` block records a start time and exiting stores the elapsed seconds in `self.elapsed`.
2. Implement `heading(title, log)` as a generator-based context manager that appends `"<title>"` on entry and always appends `"</title>"` on exit (even when the block raises).
3. Implement `module_exists(name)` using `importlib.util.find_spec` to return whether a module with that name can be found.

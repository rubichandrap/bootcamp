# Threads & Processes Challenge

Now that you have read about the GIL, threads, and processes, apply what you learned!

## Tasks

1. Implement `fetch_all(urls)` using a `ThreadPoolExecutor` so that I/O-bound `fetch` calls overlap.
2. Implement `squares_all(numbers)` using a `ProcessPoolExecutor` so that the CPU-bound `compute_square` runs across processes.

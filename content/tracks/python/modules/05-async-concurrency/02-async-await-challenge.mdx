# Async/Await Challenge

Now that you have read about coroutines and the event loop, apply what you learned!

## Tasks

1. Implement `delayed(value, delay)` so that awaiting `asyncio.sleep(delay)` suspends it and it returns `value`.
2. Implement `run_all()` using `asyncio.gather` to run three `delayed` coroutines concurrently and return `[1, 2, 3]` in input order.

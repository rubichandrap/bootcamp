# Assessment: Concurrent Toolkit

Integrate async/await, threads, and the GIL concurrency model to build a small concurrent toolkit. All three areas from this module must be applied correctly to pass.

## Tasks

1. Implement `async_task(value, delay)` as a coroutine that sleeps and returns `value`.
2. Implement `run_async_work()` using `asyncio.gather` to run three `async_task` calls concurrently and return `[10, 20, 30]`.
3. Implement `fetch_many(urls)` using a `ThreadPoolExecutor` so I/O-bound `fetch` calls overlap.
4. Implement `executor_for(kind)` returning `"thread"` for I/O-bound workloads and `"process"` for CPU-bound workloads.

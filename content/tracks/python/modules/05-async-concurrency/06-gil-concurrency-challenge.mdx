# GIL & Concurrency Models Challenge

Now that you have read about the GIL and locks, apply what you learned!

## Tasks

1. Implement `bump(shared, lock, times)` so that each increment happens inside `with lock:` and no updates are lost.
2. Implement `run_bumps(threads, times)` to run `threads` workers bumping one shared counter and return the final value.
3. Implement `mode_for(task_type)` returning `"thread"` for I/O-bound workloads and `"process"` for CPU-bound workloads.

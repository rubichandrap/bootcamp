# Generators & Pipelines Challenge

Now that you have read about generators and pipelines, apply what you learned!

## Tasks

1. Implement `evens(limit)` as a generator yielding every even number from `0` up to `limit`.
2. Implement `squares(nums)` as a generator yielding the square of each number in `nums`.
3. Implement `fibonacci()` as an infinite generator yielding `0, 1, 1, 2, 3, 5, ...`.

# itertools Challenge

Now that you have read about itertools, apply what you learned!

## Tasks

1. Implement `take(it, n)` to return the first `n` items from an iterator as a list.
2. Implement `product_pairs(a, b)` to return every `(x, y)` pair from two sequences.
3. Implement `running_sums(nums)` to return the cumulative sums of `nums`.
4. Implement `repeating(value, times)` to return `value` repeated `times` times.

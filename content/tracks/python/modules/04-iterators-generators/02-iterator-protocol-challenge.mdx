# Iterator Protocol Challenge

Now that you have read about the iterator protocol, apply what you learned!

## Tasks

1. Implement `Countdown(start)` so `list(Countdown(3))` yields `[3, 2, 1, 0]` and raising `StopIteration` once exhausted.
2. Implement `take(it, n)` to return the first `n` items from an iterator as a list.
3. Implement `interleave(a, b)` to return a list alternating items between two iterators until both are exhausted.

# Sets & Comprehensions Challenge

Now that you have read about sets and comprehensions, apply what you learned!

## Tasks

1. Implement `unique_values(items)` that deduplicates using `set()`.
2. Implement `common_elements(a, b)` using set intersection.
3. Implement `squares(n)` with a list comprehension over `range()`.
4. Implement `evens(numbers)` with a filtered list comprehension.
5. Implement `word_lengths(words)` with a dictionary comprehension.

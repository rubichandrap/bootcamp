# Dictionaries Challenge

Now that you have read about dictionaries, apply what you learned!

## Tasks

1. Implement `get_value(data, key, default)` using `.get()`.
2. Implement `add_entry(mapping, key, value)` that sets an entry and returns the dict.
3. Implement `collect_keys(mapping)` that returns a list of all keys.
4. Implement `word_count(words)` that builds a counting dictionary.
5. Implement `invert(mapping)` that swaps keys and values using `items()`.

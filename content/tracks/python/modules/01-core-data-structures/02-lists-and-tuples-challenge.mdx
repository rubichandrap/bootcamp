# Lists & Tuples Challenge

Now that you have read about lists and tuples, apply what you learned!

## Tasks

1. Implement `second_element(items)` that returns the second element using indexing.
2. Implement `last_element(items)` that returns the last element using a negative index.
3. Implement `first_three(items)` that returns a slice of the first three elements.
4. Implement `append_unique(items, value)` that appends `value` only when it is missing.
5. Implement `count_value(items, value)` that counts occurrences using `.count()`.
6. Implement `swap_pair(pair)` that returns a new tuple with the two elements swapped.

# Hello World & Function Challenge

Now that you have read about Python program structure and function syntax, apply what you learned!

## Tasks

1. Implement `hello_world()` so that it returns `"Hello, World!"`.
2. Implement `greet(name)` so that it returns `"Hello, " + name + "!"`.
3. Implement `is_even(n)` so that it returns `True` when `n` is even and `False` otherwise.

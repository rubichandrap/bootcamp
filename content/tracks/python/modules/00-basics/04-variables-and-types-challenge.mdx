# Variables & Types Challenge

Now that you have read about variables and types, apply what you learned!

## Tasks

1. Implement `add(a, b)` that returns the sum.
2. Implement `repeat(text, n)` that returns `text` repeated `n` times.
3. Implement `describe(value)` that returns a type-based description.
4. Implement `to_int(value)` that converts to an `int`, returning `None` when conversion fails.

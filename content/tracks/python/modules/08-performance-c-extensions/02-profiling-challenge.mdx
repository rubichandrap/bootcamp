# Profiling Challenge

Now that you have read about `perf_counter`, `timeit`, and `cProfile`, apply what you learned!

## Tasks

1. Implement `elapsed_ms(fn, *args, iterations=100)` to time a loop calling `fn(*args)` with `time.perf_counter` and return the total milliseconds as a float.
2. Implement `call_count(fn, *args)` to run `fn(*args)` under `cProfile.Profile` and return `pstats.Stats(profile).total_calls`.
3. Implement `timeit_seconds(fn, number=1000)` to benchmark `fn` with `timeit.timeit` and return the total seconds.

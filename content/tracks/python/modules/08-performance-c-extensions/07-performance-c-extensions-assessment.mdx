# Assessment: Native Performance Toolkit

Integrate profiling, memory inspection, and native C calls to build a small performance toolkit. All three areas from this module must be applied correctly to pass.

## Tasks

1. Implement `elapsed_ns(fn, *args, iterations=100)` to time a loop of `fn(*args)` calls with `time.perf_counter_ns` and return the total nanoseconds as an int.
2. Implement `call_count(fn, *args)` to profile `fn(*args)` with `cProfile.Profile` and return `pstats.Stats(profile).total_calls`.
3. Implement `refcount(obj)` to return the live reference count of `obj` using `sys.getrefcount` (subtracting its temporary argument).
4. Implement `same_object(a, b)` to return whether `a` and `b` are the same object via `is`.
5. Implement `c_hypot(a, b)` to call `libm.hypot` through ctypes with declared double `argtypes`/`restype`.

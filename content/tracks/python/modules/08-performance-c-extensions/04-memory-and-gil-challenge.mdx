# Memory & the GIL Challenge

Now that you have read about reference counting, memory measurement, identity, and the GIL, apply what you learned!

## Tasks

1. Implement `refcount(obj)` to return the live reference count of `obj` using `sys.getrefcount` (subtracting its own temporary argument).
2. Implement `size_bytes(obj)` to return the memory `obj` occupies using `sys.getsizeof`.
3. Implement `same_object(a, b)` to return whether `a` and `b` are the same object (identity via `is`).
4. Implement `parallel_strategy(kind)` returning `"thread"` for I/O-bound workloads (the GIL is released while waiting) and `"process"` for CPU-bound pure-Python workloads (the GIL serializes threads).

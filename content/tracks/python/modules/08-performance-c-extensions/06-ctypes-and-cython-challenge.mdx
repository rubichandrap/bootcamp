# C-Extensions Challenge

Now that you have read about `ctypes` and Cython, apply what you learned by calling a native C library through ctypes!

## Tasks

1. Implement `c_sqrt(x)` to call `libm.sqrt` through ctypes with a declared `argtypes`/`restype`, wrapping the argument in `ctypes.c_double`.
2. Implement `c_pow(base, exp)` to call `libm.pow` through ctypes with two declared double arguments.
3. Implement `has_function(lib, name)` to return whether the loaded library exposes a function with that name.

# Protocols Challenge

Now that you have read about protocol-based design, apply what you learned!

## Tasks

1. Implement `Deck` with `__len__` and `__getitem__` to satisfy the Sequence protocol.
2. Implement `Inventory` with `__contains__` to satisfy the Container protocol.
3. Implement `Multiplier` with `__call__` to satisfy the Callable protocol.

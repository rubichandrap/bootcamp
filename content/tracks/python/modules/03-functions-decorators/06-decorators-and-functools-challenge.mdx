# Decorators & functools Challenge

Now that you have read about decorators and functools, apply what you learned!

## Tasks

1. Implement `uppercase(fn)` so the wrapped function's return value is uppercased.
2. Implement `count_calls(fn)` so the wrapper counts calls in a `.calls` attribute and preserves the original name with `functools.wraps`.
3. Complete `factorial(n)` — keep the `@functools.lru_cache` decorator so repeated calls hit the cache.

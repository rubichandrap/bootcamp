# First-Class Functions Challenge

Now that you have read about first-class functions, apply what you learned!

## Tasks

1. Implement `apply_twice(func, value)` so it calls `func` twice on `value`.
2. Implement `negate(func)` to return a new function whose result is the negation of `func`'s result.
3. Implement `make_multiplier(n)` to return a function that multiplies its argument by `n`.

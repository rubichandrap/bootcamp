# Closures Challenge

Now that you have read about closures, apply what you learned!

## Tasks

1. Implement `counter(start=0)` to return a closure that yields the next integer on each call, starting at `start`.
2. Implement `make_shouter(suffix)` to return a closure that appends `suffix` to its argument.
3. Implement `make_averager()` to return a closure that keeps a running average of every number passed to it so far.

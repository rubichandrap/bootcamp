# pytest & Type Hints Challenge

Now that you have read about pytest assertions and type hints, apply what you learned!

## Tasks

1. Implement `double(x: int) -> int` to return `x * 2`, with correct type hints.
2. Implement `average(values: list[float]) -> float | None` to return the mean of `values`, or `None` when `values` is empty, with correct type hints.
3. Implement `nearly_equal(a: float, b: float, tol: float = 1e-6) -> bool` to return whether `a` and `b` are within `tol` of each other (a `pytest.approx`-style tolerant comparison), with correct type hints.

# Assessment: Project Toolkit

Integrate modules, packages, virtual-environment tooling, and type hints to build a small project toolkit. All three areas from this module must be applied correctly to pass.

## Tasks

1. Implement `module_kind(name: str) -> str` to return `"package"` when the imported module has a `__path__` attribute and `"module"` otherwise.
2. Implement `import_member(module: str, attr: str)` using `importlib.import_module` and `getattr` to load any module and return one of its attributes.
3. Implement `parse_requirements(text: str) -> dict[str, str | None]` to parse a `requirements.txt`, mapping each package to its pinned version (or `None`), ignoring blank lines and `#` comments.
4. Implement `within_tolerance(actual, expected, tol)` returning whether `actual` is within `tol` of `expected`, with correct type hints.

# Modules & Packages Challenge

Now that you have read about modules, packages, and the import machinery, apply what you learned!

## Tasks

1. Implement `module_of(func)` to return the name of the module that defines `func`, read from its `__module__` attribute.
2. Implement `import_from(module_name, attr)` using `importlib.import_module` and `getattr` to import any module by name and return one of its attributes.
3. Implement `is_package(name)` to return `True` when the imported module is a package (it has a `__path__` attribute) and `False` for a plain module.

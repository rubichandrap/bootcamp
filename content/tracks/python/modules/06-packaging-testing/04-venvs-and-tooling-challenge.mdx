# Virtual Environments & Tooling Challenge

Now that you have read about virtual environments, `pip`, `requirements.txt`, and `pyproject.toml`, apply what you learned!

## Tasks

1. Implement `parse_requirements(text)` to turn the text of a `requirements.txt` file into a dict of package names to pinned versions (or `None`), ignoring blank lines and `#` comments.
2. Implement `pinned(name, version)` to return the pip-style exact pin, e.g. `"requests==2.31.0"`.
3. Implement `project_name(pyproject_text)` to parse TOML with `tomllib` and return the project's name from its `[project]` table.

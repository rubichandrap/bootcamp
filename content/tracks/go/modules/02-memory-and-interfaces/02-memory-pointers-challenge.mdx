# Pointer Mutation & Swapping Challenge

Practice pointer dereferencing (`*`) and address manipulation (`&`)!

## Tasks

1. Implement `DoublePointer(val *int)` to double the target integer in memory.
2. Implement `Swap(a, b *int)` to swap the integer values stored at pointers `a` and `b`.

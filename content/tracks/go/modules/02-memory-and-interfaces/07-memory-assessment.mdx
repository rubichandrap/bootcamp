# Module 02 Capstone: Fixed-Size Byte Buffer

Congratulations on completing the Memory Models & Interfaces module!

To prove complete mastery over Go memory allocation, pointer receivers, slice capacity boundaries, and interfaces, implement a zero-allocation `Buffer` struct.

## Requirements

1. `NewBuffer(capacity int)` initializes an empty byte buffer with pre-allocated capacity.
2. `Write(p []byte)` appends data from `p` into `b.buf` without exceeding pre-allocated capacity and returns bytes written (`n`).

# Declaring & Using Variables Challenge

Reinforce what you just learned about `var`, short variable declarations (`:=`), and Go zero values!

## Tasks

1. Implement `FormatScore(name string, score int, passed bool) string` using `fmt.Sprintf` or string formatting.
2. Implement `GetZeroValues()` by returning uninitialized `var` variables for `int`, `string`, and `bool`.

# Control Flow Logic Challenge

Apply `if/else` conditionals and `for` loops to process numbers and categories!

## Tasks

1. Implement `CategorizeAge(age int) string` returning `"Child"`, `"Teenager"`, or `"Adult"`.
2. Implement `SumUpToN(n int) int` using a `for` loop to add up integers from `1` to `n`.

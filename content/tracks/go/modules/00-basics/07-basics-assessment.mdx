# Module 00 Capstone: CLI Metric Evaluator

Congratulations on completing the Go Syntax & Core Control Flow module!

## Requirements

1. `EvaluateScores(scores []int)` processes an slice of integer scores.
2. If `scores` is empty (length 0), return `"No scores provided"`.
3. Compute total sum and average score (`sum / count`).
4. Return string formatted as `"Processed <count> scores: Total=<sum>, Average=<avg>"`.

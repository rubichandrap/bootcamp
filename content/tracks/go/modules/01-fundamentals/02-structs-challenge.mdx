# Defining Structs & Methods Challenge

Test your understanding of struct instantiation and pointer receivers!

## Tasks

1. Implement `NewUser(name string, age int) User` to return an initialized `User`.
2. Implement pointer receiver method `(u *User) Birthday()` to increment `u.Age` by `1`.

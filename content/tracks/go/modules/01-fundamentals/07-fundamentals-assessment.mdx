# Module 01 Capstone: Entity Registry

Congratulations on completing the Composite Data Types module!

In this **CapStone Assessment**, you will demonstrate your understanding of structs, pointer method receivers, maps, and slice filtering.

## Requirements

1. `NewStore()` returns a `*Store` initialized with a non-nil `map[int]Product`.
2. `AddProduct(p Product)` adds a product to `s.products`.
3. `GetProduct(id int) (Product, bool)` looks up product by ID using comma-ok idiom.
4. `ListProductsAbove(minPrice float64) []Product` returns a slice of products with `Price >= minPrice`.

# Utility Types

TypeScript ships a set of built-in **utility types** that transform existing types. They're built using the same `keyof`, mapped types, and conditional types you've already seen — learning them gives you both immediate power and insight into how TypeScript works internally.

## `Partial<T>` — All Properties Optional

```typescript
interface User {
  id: number;
  name: string;
  email: string;
}

type PartialUser = Partial<User>;
// { id?: number; name?: string; email?: string }
```

Useful for update payloads where you only send the fields you want to change.

## `Required<T>` — All Properties Required

The inverse of `Partial`:

```typescript
type RequiredUser = Required<PartialUser>;
// { id: number; name: string; email: string }
```

## `Readonly<T>` — All Properties Immutable

```typescript
type FrozenUser = Readonly<User>;
// All properties are readonly — cannot be reassigned after creation
```

## `Pick<T, K>` — Select a Subset of Properties

```typescript
type UserPreview = Pick<User, "id" | "name">;
// { id: number; name: string }
```

## `Omit<T, K>` — Exclude Specific Properties

```typescript
type PublicUser = Omit<User, "email">;
// { id: number; name: string }
```

## `Record<K, V>` — Map Keys to Values

```typescript
type Scores = Record<string, number>;
const board: Scores = { alice: 100, bob: 85 };

type StatusMap = Record<"active" | "inactive", boolean>;
```

## `Exclude<T, U>` and `Extract<T, U>`

These work on union types:

```typescript
type Status = "active" | "inactive" | "banned";

type ActiveOrInactive = Exclude<Status, "banned">;
// "active" | "inactive"

type OnlyBanned = Extract<Status, "banned">;
// "banned"
```

## `NonNullable<T>`

Removes `null` and `undefined` from a type:

```typescript
type MaybeString = string | null | undefined;
type DefiniteString = NonNullable<MaybeString>; // string
```

## `ReturnType<T>` and `Parameters<T>`

Inspect function signatures:

```typescript
function fetchUser(id: number): Promise<User> { /* ... */ }

type FetchReturn = ReturnType<typeof fetchUser>;     // Promise<User>
type FetchParams = Parameters<typeof fetchUser>;     // [id: number]
```

These are essential when you want to derive types from existing functions without duplicating them.

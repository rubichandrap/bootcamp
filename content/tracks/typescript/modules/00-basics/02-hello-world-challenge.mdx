# Challenge: Type Annotations

Add TypeScript type annotations to all three function signatures. The logic is already correct — your only job is to annotate.

- `add(a, b)` — adds two numbers, returns a number
- `repeat(str, times)` — repeats a string N times, returns a string
- `isEven(n)` — checks if a number is even, returns a boolean
